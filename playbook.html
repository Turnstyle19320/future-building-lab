Reference manual

Vibe Coding for Educators

You do not need to become a software developer to prototype a useful classroom tool. You do need a plain-language map of what you are asking the AI to make.

Start here

What are you actually making?

Most first projects are small web apps: a page people open in a browser. The page may be one file or several files. It may save nothing, save locally, or connect to a server later.

HTML: the structure

HTML is the page skeleton: headings, paragraphs, buttons, forms, cards, links, images, and sections.

Prompt move: "Create the page structure first. Include a title, a short instruction section, an input form, and an area where results will appear."

CSS: the appearance

CSS controls the visual design: color, spacing, fonts, layout, cards, shadows, and mobile behavior. Tailwind CSS is a popular shortcut that lets the AI style quickly with reusable class names.

Prompt move: "Make this feel like a calm professional classroom tool, not a game. Use clear spacing, large readable type, and a simple card layout."

JavaScript: the behavior

JavaScript is what makes the page respond: save an entry, calculate a score, flip a card, filter a list, draw on a canvas, or update a dashboard.

Prompt move: "Add the JavaScript logic. When someone clicks the Add Evidence button, create a new card and update the summary counts."

Gemini Canvas vs. the HTML canvas element

Gemini Canvas is the AI workspace where you chat, edit, preview, and iterate.

The HTML <canvas> element is a specific piece of web code used for drawing, games, simulations, and animations.

Beginner rule: if you are building a form, checklist, flashcard set, or dashboard, you probably do not need the HTML canvas element. If you are building a game, animation, physics simulation, or free-drawing tool, you might.

Single file or folder?

Keep it simple until simple gets annoying.

For most beginners, a single HTML file is the right first win. Multi-file projects become useful when you are ready to publish, reuse assets, or edit with an agent in VS Code.

Single-file HTML

Best for first prototypes, Google Sites embeds, quick classroom tools, and activities where everything can live in one page.

evidence-dashboard.html

Multi-file project

Best for GitHub Pages, larger tools, multiple images, separate styling, and projects you want an AI coding agent to maintain.

my-tool/
  index.html
  style.css
  script.js
  assets/
    image.png
Prompt recipes

Ask for the next useful move.

Good vibe coding is not one magic prompt. It is a conversation: build, test, describe what is wrong, ask for one improvement, test again.

Ask for a simple classroom tool

"Create a single-file HTML tool for vocabulary practice. Students should see one term at a time, guess the definition, click to reveal the answer, and track how many they got right. Make it clean and readable for middle school."

Ask for an interactive dashboard

"Create a dashboard where students can add evidence of learning, tag it as growth, revision, contribution, collaboration, or reflection, and see a simple summary. Store entries in localStorage for this demo."

Ask for better styling

"This works, but it looks generic. Redesign it for teachers. Use warm neutral colors, clear hierarchy, readable font sizes, strong spacing, and buttons that are easy to find. Do not make it childish."

Ask for debugging help

"The Add button does not create a new card. Read the code, explain the likely cause in plain language, then give me a corrected full file."

Ask for a multi-file version

"Split this into three files: index.html for structure, style.css for design, and script.js for behavior. Keep the same functionality."

Toolkit

Optional ingredients, not requirements.

These are useful words to recognize. Nobody needs all of them on day one.

Tailwind CSS

Fast styling

Useful when you want the AI to make a page look polished quickly.

Lucide Icons

Simple icons

Useful for buttons, sections, and navigation when text alone feels flat.

Google Fonts

Better typography

Useful when the page needs to stop looking like a default document.

SVG

Diagrams and shapes

Useful for static diagrams, game boards, and icons that scale cleanly.

Canvas

Drawing and games

Useful for simulations, animations, and pixel-based movement.

Three.js

3D in the browser

Advanced. Useful for 3D scenes, but not necessary for normal classroom tools.

What comes later

When the project grows up

After a first static prototype, some tools need live collaboration, join codes, cloud databases, or a real development environment. That is a new stage, not the starting line.

VS Code + an agent

Use this when the project has folders, multiple files, repeated changes, or needs careful debugging.

Node.js + WebSockets

Useful for live join-code activities where devices need to talk to each other in real time.

Cloudflare or Firebase

Useful for real hosted backends and databases, but this is where data privacy and district approval questions become serious.
