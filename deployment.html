After it works

Share and Store

Before choosing a platform, answer two questions: who needs to open it, and where does the data live?

The ladder

Do not overbuild the first version.

Move down the ladder only when the project actually needs the next level. A flashcard tool does not need Firebase. A live join-code activity probably needs more than Google Sites.

Draft

Keep it in Gemini Canvas, ChatGPT, Claude, or another AI workspace while you are still shaping the idea.

Embed

Use Google Sites or an LMS when the tool is one self-contained HTML file and belongs near class materials.

Publish

Use GitHub Pages when the project needs a clean public URL or multiple files.

Develop

Use VS Code plus an AI coding agent when the project becomes a folder you maintain.

Connect

Add Node.js, WebSockets, Cloudflare, Firebase, or another backend only when devices or users need to share live data.

Storage examples

Where the data goes matters more than how fancy the page looks.

These three examples can look similar on screen, but they create very different responsibilities.

No Storage

Timer resets when closed.
