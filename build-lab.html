Evidence of Impact Dashboard

A small prototype for the Feedback First Firewall: move from points as currency to evidence as currency.

Starter prompt

Build version one.

Use this in Gemini Canvas, ChatGPT, Claude, or the AI coding tool available to you. The goal is not the perfect app. The goal is a working first artifact.

Create a single-file HTML web app called "Evidence of Impact Dashboard."

Audience: middle or high school students.

Purpose: replace points-as-currency with evidence-as-currency.

The app should let a student:
1. Add a short description of something they contributed, revised, built, helped, or learned.
2. Choose an evidence type: growth, contribution, revision, collaboration, or reflection.
3. Choose an impact level: small, medium, or big.
4. See their entries appear as cards on the page.
5. See a simple summary count by evidence type.

Make it polished but not childish. Use HTML, CSS, and JavaScript in one file.
Do not use external databases or accounts.
Store entries in localStorage so the demo works on one device.
Step one

Get one working thing

If it accepts an entry, shows the entry, and summarizes evidence types, version one is successful.

Step two

Make the process visible

Ask the AI what each part does. Have it label HTML, CSS, and JavaScript in plain language.

Step three

Bend it toward your goal

Change the evidence types, language, dashboard, or audience so it supports your actual work.

Remix prompts

Make it yours.

These prompts keep beginners moving without needing to understand the whole codebase yet.

Change the audience

“Revise this for elementary students. Use simpler language, fewer fields, and a more visual summary.”

Add reflection

“Add a reflection prompt that asks: What changed because of this work?”

Make it teacher-facing

“Turn this into a teacher conference tool for collecting evidence before student check-ins.”

Improve the design

“Make the interface feel like a serious portfolio tool, not a behavior tracker.”
