The session arc

Slides orient. Pages support.

The deck should not carry every technical detail. Use the slides to guide the room, then point people to the pages when they need recipes, deployment help, file structure explanations, or privacy cautions.

01

Remember the February prompt

Show the original “dissolve the problem” activity and the first-pass futures that were imaginative enough to be useful, but not yet actionable.

02

Make the teacher-led pivot

Move from policy-scale fantasy to local experiments: evidence of impact, student-owned work, and community validation.

03

Build one artifact

Everyone starts with the same simple prototype, then bends it toward their own classroom goal or district problem.

First pass

Interesting does not mean usable.

Surveillance as solution

Automated enforcement can accidentally replace relationship, judgment, and trust.

Policy vacuums

Some ideas need governors, legislatures, budgets, and years. That does not help a teacher tomorrow.

Tech magic

If the tool “dissolves” workload, dyslexia, motivation, and complexity overnight, it is probably skipping the hard human part.

The bridge

Build the smallest support beam.

The realistic version of a radical idea is something a real person can test, revise, and share. That is the point of vibe coding here.
