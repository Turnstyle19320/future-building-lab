How the morning flows

Three short moves, in order.

1

Set the table with the slides

A quick look at what this group imagined back in February, what was worth keeping, and what an educator-sized version of those ideas might look like. Maybe 15 minutes.

2

Vibe code one thing together

We all open the same AI tool — Gemini Canvas is the easy default, but Claude or ChatGPT works too — and build a tiny thing side by side. Just to feel how the conversation works. Then I'll show how that same little thing could become a real app you actually use.

3

You build yours

This is the main event. Pick a thing you've been wishing existed in your classroom, your team, or your life. Start building it. I'll be circulating. The pages on this site are there when you hit a wall.

Learning targets for today

What you can leave saying.

Must Do

If I learn nothing else.

  • I can make one small web thing today with AI doing the typing.
  • I can point at HTML, CSS, and JS in what the AI gives me and say which is which.
  • I can describe what a "folder of files" is and where I'd save mine.
Could Do

If I get into the flow.

  • I can save my file to my desktop, double-click it, and watch it run as a real web page.
  • I can name a few tools to ask the AI for — Tailwind, Lucide, Google Fonts, Chart.js — and see the difference.
  • I can drop in a visual moment: a chart, confetti, an icon, a pattern.
Aspire to Do

If I'm running ahead.

  • I can explain a few ways a tool might eventually get online, even if my district account blocks some of them.
  • I can add something that remembers things — localStorage, or the taskFlow trick with Apps Script.
  • I can start my second tool — the one only I would think to build for my students.
Existence proof

I'm not a developer. These are mine.

Each of these started as a folder on my desktop. I asked AI for help, kept iterating, and used the simplest tools that would do the job.

Simplest tier

taskFlow

A personal task tracker that syncs across my devices. I literally asked AI: "what's the simplest way to sync this without a complicated cloud setup, using tools I already have?" It pointed me at Google Apps Script + Google Drive. No servers. No database. Just files.

Open taskFlow → Live collaboration

CoSN K-12 AI Maturity Assessment

A facilitated assessment that syncs across everyone's devices in real time. The host shares a room code, participants join, and updates propagate live — peer-to-peer through PeerJS. Still no backend, just a static site.

Open the tool → What's possible

UnscriptED.fit

A more ambitious build that started the same way: a folder on my desktop, a conversation with AI, and a problem I wanted solved. Same ladder, just a few more rungs.

Visit unscripted.fit → Different shape

PrepPanel

A Chrome extension I built for myself, packaged so other people could use it too. Different format, same starting point: a folder, AI as a collaborator, and the willingness to keep going when something broke.

Visit preppanelclassroom.com →
The thing nobody told me

"I don't need to wait for someone to build the thing I want."

That's the whole shift. Not "everyone should learn to code." Not "AI replaces teachers." Just: the gap between an idea and a working version of it is smaller than it has ever been, and the tools to close that gap are sitting on your computer right now.
